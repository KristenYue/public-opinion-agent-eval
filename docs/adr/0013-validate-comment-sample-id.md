# ADR-0013：在 API 边界校验评论 sample_id

- 状态：已接受
- 日期：2026-08-11

## 背景

`CommentInput.text` 已限制为空时拒绝请求，但 `sample_id` 原先只声明为字符串，空字符串仍能进入 Agent 工作流。`sample_id` 用于关联评论级分类、复核结果和审计记录；空标识会削弱结果定位能力，并可能让下游重复标识检查失去意义。

## 决策

在 Pydantic API 模型中将 `sample_id` 约束为 1–200 个字符。无效请求由 FastAPI 在进入 Graph 前返回 HTTP 422。

## 备选方案

1. 在分类节点内检查：拒绝得太晚，Graph 和模型依赖可能已被初始化。
2. 自动生成缺失标识：会掩盖调用方数据质量问题，也改变外部标识的来源语义。
3. 只在 Reviewer 阶段检查：快速路径仍可能产生不可审计结果。

## 影响

- 所有有效请求行为不变，Benchmark 和模型指标口径不变。
- 空 `sample_id` 请求从 HTTP 200 改为 HTTP 422。
- 新增回归测试，当前全量测试由 90 项增加到 91 项。
