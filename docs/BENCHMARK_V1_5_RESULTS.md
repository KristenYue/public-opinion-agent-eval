# Benchmark v1.5 最终结果

## 一句话结论

在按事件隔离的 6 个未见测试事件、339 条评论上，事件感知纯自动级联将 Accuracy 从 XGBoost 基线的 **31.27%** 提升至 **56.05%**，提高 **24.78 个百分点**；系统自动处理 78.76% 的样本时，选择性自动 Accuracy 为 **66.67%**。其余 21.24% 进入人工兜底。

## 冻结协议

- 总规模：599 条评论、12 个事件。
- train：225 条、5 个事件。
- validation：35 条、1 个事件，仅用于在 `0.50 / 0.65 / 0.80` 中选择阈值。
- test：339 条、6 个未见事件，阈值锁定后只执行一次正式评测。
- 最终阈值：`0.80`。
- 事件隔离检查：通过。
- 待复核标签：0。
- 测试标签分布：Negative 144、Neutral 83、Positive 95、Unscorable 17。
- Qwen 输出对人工标签盲态，模型为 `qwen-plus`，提示词版本为 `event_stance_v2`。

## 主要指标

| 口径 | Accuracy | Macro-F1 | Negative Recall | 说明 |
|---|---:|---:|---:|---|
| XGBoost 基线 | 31.27% | 26.17% | 17.36% | 本科模型在新事件上的分布外基线 |
| 纯自动事件感知级联 | 56.05% | 45.13% | 57.64% | 全部测试样本，不使用人工标签 |
| 选择性自动 | 66.67% | 53.22% | 70.09% | 只统计自动放行的 78.76% 样本 |
| 完整工作流 | 73.75% | 62.65% | 75.69% | 其余 21.24% 使用人工标签模拟接管 |

必须正确解释四种口径：

- **31.27%** 是旧 XGBoost 的跨事件基线，不是项目最终能力。
- **56.05%** 是可以称为“纯自动全量 Accuracy”的主模型指标。
- **66.67%** 是选择性预测结果，只适用于系统自动放行的样本，必须同时报告 78.76% 覆盖率。
- **73.75%** 是含人工兜底的端到端工作流结果，不是模型准确率。

## 消融结果

| 阶段 | Accuracy | Macro-F1 | Negative Recall |
|---|---:|---:|---:|
| XGBoost 基线 | 31.27% | 26.17% | 17.36% |
| + 分歧路由与高置信 Qwen | 50.44% | 41.14% | 47.92% |
| + 事件感知路由与上下文 Qwen | 56.05% | 45.13% | 57.64% |
| + 人工兜底的完整工作流 | 73.75% | 62.65% | 75.69% |

相较 XGBoost，Qwen 在冻结测试中修正了 **85** 个错误，并造成 **1** 次 harmful override。这说明复核器整体有明显净收益，同时也证明“大模型覆盖并非永远正确”，保留置信门禁和人工接管是必要的。

## 不确定性

固定随机种子、按人工标签分层的 2,000 次评论级 bootstrap 结果：

| 口径 | Accuracy | 95% CI |
|---|---:|---:|
| XGBoost 基线 | 31.27% | 26.84%–36.28% |
| 纯自动事件感知级联 | 56.05% | 50.74%–61.36% |
| 选择性自动 | 66.67% | 61.48%–72.08% |
| 完整工作流 | 73.75% | 69.32%–78.17% |

这些区间只衡量当前冻结事件内的评论级抽样不确定性，不是事件聚类置信区间，也不证明对所有未来事件的泛化能力。

## 跨事件表现

纯自动 Accuracy 在 6 个测试事件上介于 **47.69%–67.69%**，完整工作流 Accuracy 介于 **65.00%–85.00%**。事件间差异说明该项目仍需要按事件监控，而不能用单个总体平均数掩盖困难话题。

## 生产一致性修正

正式评测首次运行时，有 3 条有效短文本在 XGBoost 预处理后变为空字符串。评测在产生任何最终指标前中止；随后只做了与生产 Agent 一致的失败关闭修正：

- XGBoost 将此类输入记为 `Unscorable`、置信度 `0.0`；
- 样本仍保留在冻结测试集中并继续走风险路由；
- 没有删除样本、修改标签、调整提示词或查看结果后调阈值。

修正记录见 `data/evaluation/benchmark_v1_5_freeze_amendment_002.json`。

## 对外表述边界

推荐表述：

> 构建 599 条、12 事件的上下文标注评测集，采用事件级 train/validation/test 隔离；在 6 个未见事件、339 条冻结测试评论上，将纯自动 Accuracy 从 XGBoost 基线 31.27% 提升至 56.05%，选择性自动 Accuracy 达 66.67%（78.76% 自动覆盖），并通过置信门禁将 21.24% 的不确定样本转人工。

禁止表述：

- “模型准确率 73.75%”——该数字包含人工标签模拟兜底。
- “达到生产级准确率”——当前证据不足以支持生产 SLA。
- “在所有新事件上泛化稳定”——6 个事件仍只能提供有限的跨事件证据。
