# Reviewer 置信度分层诊断

## 范围

本报告复用 Benchmark v1.5 冻结测试集的 339 条人工标签和盲态 Qwen 响应，没有发起新的 API 调用，也没有重新选择路由阈值。

- 测试事件：6 个未见事件
- 测试评论：339 条
- 路由阈值：0.80（XGBoost/路由阈值，不是 Qwen 置信度）
- 短文本门限：4 字符
- Qwen 置信度：`High / Medium / Low` 自报等级

## 置信度分层

| Qwen 自报置信度 | 数量 | Accuracy |
|---|---:|---:|
| High | 267 | 70.79% |
| Medium | 66 | 24.24% |
| Low | 6 | 16.67% |

High 档明显优于 Medium/Low，支持当前“仅 High 允许自动覆盖”的保守门禁。不过这不是概率校准：`High` 不能解释为 70.79% 的预测概率，也不能直接外推到新模型、新 Prompt 或未来事件。

## 无条件采用 Qwen

| 指标 | 结果 |
|---|---:|
| XGBoost Accuracy | 31.27% |
| 无条件 Qwen Accuracy | 60.77% |
| 标签覆盖次数 | 122 |
| 纠正基线错误 | 103 |
| 有害覆盖 | 3 |
| 错误改成另一错误 | 16 |
| 净纠错 | 100 |

无条件采用带来更高总体准确率，但仍产生 3 次有害覆盖，且无法处理 Qwen 不确定时的风险。

## 受控门禁

| 指标 | 结果 |
|---|---:|
| fast path | 47 |
| Qwen 自动复核 | 220 |
| 人工复核 | 72 |
| 自动覆盖次数 | 93 |
| 纠正基线错误 | 85 |
| 有害覆盖 | 1 |
| 错误改成另一错误 | 7 |
| 净纠错 | 84 |
| 纯自动 Accuracy | 56.05% |
| 选择性自动 Accuracy | 66.67% |
| 自动覆盖率 | 78.76% |

门禁牺牲了一部分无条件采用 Qwen 的纠错收益，但将 harmful override 从 3 次降到 1 次，并把 72 条 Medium/Low 或不确定样本转入人工流程。

## 结论

当前证据支持以下工程决策：

1. `High` 结果在满足事件感知路由条件时才允许自动覆盖；
2. `Medium/Low` 不自动改变最终标签，进入人工复核；
3. Qwen 置信度是行为门禁信号，不是连续概率；
4. 必须同时报告纠错数、harmful override、自动覆盖率和人工率，不能只报告 Accuracy。

以下项目需要新 API 调用，不能从单次冻结响应推断：

- 同一样本重复调用的一致率；
- 显示/隐藏 XGBoost 结果后的锚定偏差；
- 标签枚举顺序敏感性；
- 证据顺序敏感性。

后续实验应从冻结测试集外建立独立诊断集，固定模型、Prompt 和温度，对每个条件至少重复 3 次；原始响应、Token、延迟和失败均需保存。该实验不得用于回头修改 Benchmark v1.5 测试结果。
